## 1. 项目目标

本项目用于训练 **heatmap → roof plan** 的图像到图像生成模型，数据是 1:1 配对样本（约 40 对）。

- 输入：热力图（heatmap）
- 输出：屋顶平面图（roof plan）
- 任务类型：配对监督图像翻译

## 3. 数据准备与校验

### 3.1 目录格式

```text
DATA_ROOT/
  heatmap/
    0001.png
    0002.png
  roof/
    0001.png
    0002.png
```

要求：同名文件必须成对存在。

### 3.2 先做配对检查（强烈建议）

```bash
python scripts/check_dataset_pairs.py --data_root /path/to/DATA_ROOT
```

- 若返回 `[OK]`，说明配对完整。
- 若报错，会显示仅存在于某一侧的样本名示例。

## 4. 预处理（同步裁剪）

由于 roof 图常有大面积白边，先做同步裁剪可以显著提高小样本训练效果。

```bash
python scripts/preprocess_dataset.py \
  --data_root /path/to/DATA_ROOT \
  --out_root  /path/to/DATA_ROOT_CROPPED \
  --out_size 512 \
  --white_thresh 245 \
  --pad 16
```

处理逻辑：
1. 在 roof 图中找非白区域 bbox；
2. 按分辨率比例映射到 heatmap 同步裁剪；
3. 双方 pad 成方形并 resize 到 512。

## 5. 训练方案 A：SA-Img2Img

新手建议先跑这个，训练链路更直接。

```bash
python scripts/train_sa_img2img_gan.py \
  --data_root /path/to/DATA_ROOT_CROPPED \
  --out_dir outputs/sagan_roof \
  --image_size 512 \
  --batch_size 2 \
  --lr 2e-4 \
  --epochs 200 \
  --seed 42 \
  --val_ratio 0.2 \
  --split_seed 42
```

## 6. 训练方案 B：ControlNet

```bash
accelerate launch scripts/train_controlnet.py \
  --pretrained_model_name_or_path runwayml/stable-diffusion-v1-5 \
  --output_dir outputs/controlnet_roof \
  --data_root /path/to/DATA_ROOT_CROPPED \
  --resolution 512 \
  --train_batch_size 1 \
  --gradient_accumulation_steps 4 \
  --learning_rate 1e-5 \
  --max_train_steps 2000 \
  --validation_steps 200 \
  --prompt "a roof plan" \
  --seed 42 \
  --val_ratio 0.2 \
  --split_seed 42
```

说明：当前版本已修复 ControlNet 训练时的梯度链问题（UNet 参数冻结，但不再切断反传路径）。

## 7. 结果查看与指标解释

主要看：
- `samples/` 或 `validation/` 可视化结果
- `metrics.csv` 指标曲线

指标含义：
- **L1**：越低越好（像素误差）
- **PSNR**：越高越好（重建质量）
- **SSIM**：越高越好（结构相似性）

---

## 8. 小样本（40 对）实战建议

1. 先固定 512 分辨率跑通。
2. 保持固定验证集（`split_seed` 固定）。
3. 每隔一定 step 看可视化，防止过拟合后继续无效训练。
4. 优先保证对齐质量，再考虑提分辨率。

---

## 9. 常见问题排查

- **显存不足（OOM）**：先降 `batch_size`，再降 `max_train_steps` 或 `resolution`。
- **数据路径错误**：确认确实存在 `heatmap/` 与 `roof/`。
- **配对不齐**：先运行 `check_dataset_pairs.py` 修复文件名。
- **Colab 断连**：定期打包下载 `outputs/`。
